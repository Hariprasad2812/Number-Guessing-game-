# 🎮 Neon Hunter Game

A fun and interactive neon-themed browser game built with **HTML, CSS, and JavaScript**. The project combines engaging gameplay with a modern neon-style interface and visual effects.

## ✨ Features

* 🎮 Interactive gameplay
* 🌈 Modern neon-themed UI
* ✨ Visual effects and animations
* 📱 Responsive design
* ⚡ Lightweight and fast
* 🌐 Runs directly in a web browser
* 🖥️ No installation required

## 🛠️ Technologies Used

* **HTML5** – Game structure
* **CSS3** – Styling, animations, and neon effects
* **JavaScript** – Game logic and interactions

## 🚀 How to Run

### Option 1 — Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing! 🎮

### Option 2 — GitHub Pages

The game can be hosted using **GitHub Pages**.

1. Go to **Settings** in the repository.
2. Select **Pages**.
3. Choose the `main` branch.
4. Select the `/ (root)` folder.
5. Click **Save**.
6. Open the generated GitHub Pages URL.
